## 🚀 Tech Stack & Design System
- **Framework**: React 18 + Vite (Blazing Fast SPA)
- **Styling**: Tailwind CSS with custom royal theme tokens (`royal-dark`, `royal-navy`, `royal-gold`, `royal-emerald`, `royal-crimson`, `royal-card`)
- **Typography**: 
  - Royal Headings: `Cinzel` & `Cormorant Garamond`
  - Clean UI & Body: `Plus Jakarta Sans`
  - Romantic Wedding Flourish: `Great Vibes`
- **Icons**: Lucide React
- **Interactive Enhancements**:
  - Dynamic Event Cost Estimator with live price calculations & WhatsApp quote generator
  - Filterable Photo & Video Gallery with Fullscreen Lightbox
  - Web Audio API Royal Tanpura/Sitar Ambient Music Synthesizer
  - Canvas Confetti celebrations
  - Responsive Mobile Navigation Drawer
  - Quick Date Availability checker bar
  - Interactive Google Maps integration

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in `/dist`.

### 4. Preview Production Build
```bash
npm run preview
```
